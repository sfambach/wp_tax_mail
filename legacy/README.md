# Legacy

`kaeufe-import/` is a reference copy of the Python mail importer that ran on the owner's PC
(fetch order mails via IMAP, parse them per shop, write purchases/sales via `taxmod/write-data`).
It is kept only as a template for the PHP port in this plugin; the plugin does not run it.
All mails, receipts, sample data and credentials were removed; the `*.ini.example` files contain placeholders only.
